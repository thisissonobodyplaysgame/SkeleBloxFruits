FAQ

Questions from the greedy

Where do the values come from?

A scheduled GitHub Action reads the community value list, pulls every item with its Beli value, permanent value, Robux price, demand and last update time, and writes it to a JSON file in this repo. The page loads that file on every visit, so the numbers here are never hand typed. The last sync time is shown in the pill at the top of the page.

Where does the stock come from?

A scheduled job reads the live Blox Fruits dealer feed every 10 minutes and writes the current rotation to a JSON file, and this page re-reads that file on the same cadence. If a rotation window closes before a newer one is published, the cards show the last lineup we were actually told about, labelled last known — the site never invents a rotation, because a plausible-looking guess is worse than an honest gap. A Discord bot can post the same job instead if you prefer that source.

When does stock reset?

The Normal Blox Fruit Dealer resets every 4 hours on the UTC clock at 00:00, 04:00, 08:00, 12:00, 16:00 and 20:00 UTC. The Mirage Dealer on Mirage Island resets every 2 hours, twelve times a day. The countdown under each dealer name shows the time left in your own timezone.

Does server hopping get better stock?

No. Stock is global and anchored to UTC, so every server shows the same rotation at the same moment. Waiting for the reset is the only way to change the fruit list.

Beli value or permanent value, which one do I use?

Use Beli value, because that is the tradeable version and what almost every trade is agreed on. Switch a slot to permanent only when the other side is actually offering the gamepass version, because permanent values sit on a different scale.

What does demand mean?

Demand is a 1 to 10 rating of how many players want the item. High demand items hold value longer and sell faster, which is why a 9 demand fruit is usually worth more than a 4 demand fruit with a similar Beli price.

How close is close enough?

The calculator calls a trade even when the two sides are within 5% of each other, because real trades always carry a little timing and demand risk. Anything past that is reported as a win or a loss with the exact gap.

Why can only three stats be maxed?

Each level gives 3 points shared across five stats and a single stat caps at 3,000. At max level you hold 9,000 points, which is exactly three full stats, and that is where the classic melee, defense and one damage stat build comes from.

No. This is a fan project. Blox Fruits is made by Roblox Corporation and all trademarks belong to their respective owners. Values are community estimates and can be wrong, so always sanity check against live trade ads.
